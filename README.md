# Pinnacle Accountants LLP Website
## Overview
This project is a 3-page website for Pinnacle Accountants LLP, an accounting firm specializing in financial services. The website is designed to generate leads by providing clear, informative content and a user-friendly experience.

## Pages
### Homepage:

Highlights the firm's key services: Accounting, Tax Planning, Advisory, Assurance, and Corporate Secretarial.
CTA: Request a consultation.

### About Us:

Explains the firm's expertise, technology-driven solutions, and client focus.
CTA: Request a consultation.

### Contact Us:

Includes a contact form for inquiries and a subscription option for a free financial health check guide.

## Technologies Used
HTML5 and CSS3 for page structure and styling.
Bootstrap for responsive design and layout.

## Features
Fully responsive design using the 12-column grid system in Bootstrap.
Interactive contact form and email subscription option.
